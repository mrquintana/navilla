# Frontend Overview

The Navilla frontend is a React application built with Vite and TypeScript.

## Technology Stack

| Technology | Version | Purpose |
|------------|---------|---------|
| React | 19.2.0 | UI framework |
| TypeScript | 5.x | Type safety |
| Vite | 7.2.4 | Build tool |
| TailwindCSS | 3.x | Styling |
| React Router | 6.x | Routing |
| TanStack Query | 5.x | Data fetching |
| Supabase JS | ^2.93.3 | Auth client |

## Design System

Following the product requirements:

| Aspect | Choice |
|--------|--------|
| Style | Minimal, clinical, black & white |
| Font | Inter (headings/body), JetBrains Mono (stats) |
| Colors | Neutral palette with muted accents |

## Key Screens

1. **Onboarding** - Privacy explanation, consent
2. **Dashboard** - Exposure snapshot, quick stats
3. **Connections** - List, add new, pending requests
4. **Health Status** - Personal records, add new
5. **Alerts** - Exposure notifications
6. **Settings** - Account, privacy, notifications
